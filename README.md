# ヒカリレフレックス — Hikari Reflex

Meta Ray-Ban Display 用の反射神経テストゲーム。画面が緑にフラッシュした瞬間にタップし、反応速度を競います。

- **ライブURL**: https://hikari-reflex.vercel.app
- **画面**: 600×600 / 加算式ディスプレイ対応（背景 #000000 = 透明）
- **依存ライブラリなし**（Vanilla JS / 静的サイト）

## 特徴

- **5ラウンド制の反射神経テスト** — 「まて…」の後、ランダムな待ち時間（1.5〜4秒）を経て画面が緑にフラッシュ。フラッシュした瞬間からタップまでの時間を `performance.now()` でミリ秒単位計測
- **フライング判定もやさしい設計** — 早すぎるタップは「はやすぎ！」と表示した後、同じラウンドをやり直すだけ（ペナルティなし）
- **平均・ベストタイムを集計** — 5ラウンド終了後に平均タイムとベストタイムを表示、反応速度に応じたコメント付き
- **自己ベストを記録** — 歴代の最速タイムを `localStorage` に保存し、次回以降のプレイでも表示・更新
- ミニマルな見た目でフラッシュの瞬間に集中できるデザイン
- すべてタップ＋D-padスライドだけで往復可能

## 操作方法

| 画面 | 操作 |
|------|------|
| ホーム | 「スタート」にフォーカス、タップでゲーム開始 |
| ラウンド画面 | 緑にフラッシュしたら即タップ。早すぎるとやり直しになります |
| 結果画面 | 「もう一度」で再挑戦、「← もどる」でホームへ |
| PC確認用 | Escape で戻る（グラスの戻るジェスチャーは使用不可のため補助のみ） |

## グラスへの登録

`qr-publish.png` の QR コードをスマホでスキャンすると Meta AI アプリが開き、自動で Web アプリとして登録されます。

ディープリンク:
```
fb-viewapp://web_app_deep_link?appName=%E3%83%92%E3%82%AB%E3%83%AA%E3%83%AC%E3%83%95%E3%83%AC%E3%83%83%E3%82%AF%E3%82%B9&appUrl=https%3A%2F%2Fhikari-reflex.vercel.app
```

手動登録の場合: Meta AI アプリ → デバイス → ディスプレイグラス設定 → アプリ接続 → Web アプリ → 「Web アプリを追加」で名前 `ヒカリレフレックス`、URL `https://hikari-reflex.vercel.app` を入力。
